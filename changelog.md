# Changelog

All notable changes to Omnidex are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Omnidex is an Electron 41 + React 19 desktop app for organizing local Unreal
Engine assets. The renderer talks to the Electron main process over tRPC v11
(via electron-trpc, serialized with superjson). Data lives in a local
better-sqlite3 database with raw `.up.sql` migrations, and a Rust napi-rs addon
(`@omnidex/uasset`) parses `.uasset`/`.umap` files and extracts thumbnails.

## [Unreleased]

`package.json` is still at 2.0.7. Entries cite the pull request (`#N`) or, for
work that reached `main` through direct merges with no pull request, the commit.

### Added

- Multi-select in the asset grid, table and collection views: click,
  Ctrl/Cmd-click, Shift-click ranges, Ctrl/Cmd-A for the filtered set, Esc to
  clear. A floating bar applies Favorite, New collection, Add tags and Remove to
  the selection, and a status bar shows the shown and total counts. Add tags
  only adds; it never replaces existing tags. (#36, #40)
- Table view next to the grid. A card with no thumbnail swaps the empty image
  area for the full name, ecosystem, size and engine range. (#36)
- Collection cards show a 2x2 mosaic of the four most recently added assets and
  an "N assets · size" line. (#36)
- Inspector tabs (Details, Description, Technical), action buttons pinned in a
  footer, and provenance: scan location, full path with a copy button, and a
  duplicate count. (#36)
- Toolbar search ranks results with FTS5/BM25 over name, marketplace title,
  seller and tags, and it keeps the active sidebar facets applied. (#32, #36)
- Sidebar facets combine (for example, unmatched Blender packs). The active set
  shows as removable chips above the grid. A Marketplace group adds Orbital
  matched and Unmatched. (#33, #36)
- Match tab: a queue of unmatched packs, largest first, with disk facts beside
  marketplace facts. "Not this one" offers the next candidate and "Not on
  Orbital" removes the pack from the queue; both survive a restart. (#36, #39)
- Inspector "Find match" / "Change match": pick from ranked Orbital candidates
  or search by hand to correct an asset's marketplace match. (#28)
- Library health page (`/health`) listing what a scan skipped: archive-only
  folders, packs buried past the depth limit, thumbnail failures, and paths near
  the Windows length limit. (a4511a3)
- Per-folder content type ("Contains": Courses or assets) in the scan-location
  editor. The scanner stamps it on every asset from that folder, and changing it
  reclassifies the folder on the next scan. A course folder is walked flat: each
  top-level folder is one course. (a4511a3, #36)
- Thumbnails for packs with no `.uasset`, taken from a preview image the pack
  ships. Sizes truncated by the walker's file cap are marked partial instead of
  shown as exact. (a4511a3)
- Settings > Marketplace "Sync FAB library" button. A stale Epic login shows an
  "Open Epic login" action instead of an error. (#23)
- Settings > Folders "Scan all" button. Folder rows show asset count, size on
  disk and last scan. (#24, #36)
- Learn course index: chapters and lessons in author order, lesson durations
  read from MP4 headers, a resume position per lesson, vendor attribution from
  folder names, and titles and cover art recovered from disk. Unextracted
  multi-part archives are labelled as archives to extract instead of "0 videos".
  `pnpm backfill:course-sources` attributes vendors for courses already
  indexed. (#36)
- Learn player captions from the subtitle sidecars (SubRip is converted to
  WebVTT on the fly). When a lesson has several sidecars, English is preferred.
  (#39, #50)
- MPEG-TS (`.ts`) lessons are indexed, detected by packet sync bytes so
  TypeScript sources are not mistaken for video. The player reports a container
  the browser cannot decode and offers the default player. `pnpm remux` rewrites
  such lessons to MP4 without re-encoding and keeps the originals. (#39, #41,
  #44)
- Ask this course (Learn > course detail): streamed answers from a local
  OpenAI-compatible server or headless Claude Code, with `[[lesson@seconds]]`
  citation chips that seek the player. Provider and context budget are set in
  Settings > AI. (#46)
- Oracle MCP server (`scripts/oracle-mcp/server.mjs`) with `search_transcripts`,
  `get_context`, `list_courses`, `search_lessons` and `search_assets`.
  (#37, #49)
- Whisper backfill (`scripts/asr/backfill.py`) that writes `.srt` sidecars the
  scanner ingests, English translation for foreign-language lessons, and
  `--only transcribe|translate` to run one pass without the other. (#37, #50,
  #53)
- Founders Grotesk as the primary typeface, with Capsize-trimmed `cap-N` type
  classes generated by `pnpm capsize`. (#22)
- Developer handbook in `docs/devbook/` (mdBook, one Diátaxis mode per page) and
  `DESIGN.md` v2, which replaces two conflicting design specs with one. (#54,
  #36)

### Changed

- Navigation is three tabs: Library, Match and Learn. Collections and Library
  health moved into the sidebar. (#36)
- Settings is a routed page (`/settings/<tab>`) instead of a dialog, so each tab
  has an address and Back walks through them. Tabs are Folders, Marketplace,
  Storage, AI and About. Storage replaces System with database path and size,
  thumbnail-cache size and a confirmed purge, log folder, per-folder disk use,
  and a Copy diagnostics button. (#36)
- Rating, review and price sorts show how many assets they cover ("N matched")
  instead of posing as library-wide. (#36)
- Transcript cues live in an indexed `transcript_cues` table, with
  `transcript_fts` as an external-content index over it. A one-time migration at
  first launch drops cues orphaned by earlier scans (60% of the rows on the
  measured library) and takes about 11 seconds on 4.6 million cues. Search
  ranking no longer counts stale rows, and `get_context` drops from about 1.1 s
  to under 1 ms. (#51)
- Orbital matching scores long pack names with a word-set similarity beside the
  fuzzy score, so an exact long name is no longer rated low. The word-set score
  only ever raises a confident match. (12c2de5, f133764)
- CI runs on `main`. The pre-commit hook passes when no staged file is one Biome
  handles. (#35)

### Fixed

- Windows: every local thumbnail was rejected by the `omnidex-asset://` handler
  because Chromium dropped the drive colon from the URL. (b6ea674)
- Video seeking and Learn's resume-at-position: the asset protocol now answers
  range requests with `206` and `Content-Range`. (#42)
- Renaming or moving a pack folder no longer deletes its collection membership,
  tags and notes. The scan marks such rows missing instead of deleting them.
  (#36)
- One malformed `.uasset` no longer aborts a whole scan. Thumbnail extraction
  runs in disposable child processes, and a crashed file is retried alone before
  it is reported as malformed. (#51, #52)
- Search returned courses and soft-deleted packs that the grid excluded. Both
  now share one filter. (#36)
- Course chapters sorted as 1, 10, 11, 2; they now sort numerically. (#36)
- Text with descenders was clipped under Capsize's trimmed line box. (#36)
- Subtitle sidecars named `<video>.mp4.srt`, which the Whisper backfill writes,
  never paired with their video. (#39)
- A fresh install gave Ask an 8k context budget instead of the default. (#48)
- The Orbital API returns price and rating as strings for some items, which
  crashed the match picker. They are converted to numbers when read. (#29)
- `pnpm gen:test-library` failed on Windows because one generated pack name
  contained a character Windows paths forbid. (#38)
- The scan progress panel stopped updating after the first route change.
  electron-trpc closed every subscription on each hash navigation while the
  renderer still believed it was subscribed; a patch now leaves same-document
  navigations alone. (#64)

### Removed

- The `/fab` and Projects tabs, and the Settings "Version control" tab. (#36)
- The `assets.listByCategory` tRPC procedure and its repository function,
  replaced by the sidebar `match_status` facet. (#33)
- BMAD tooling. The Orbital classify scripts moved to `scripts/`. (df7d20d)

## [2.0.7] - 2026-06-13

This is the current release. The macOS installer
(`dist-installer/Omnidex-2.0.7-arm64.dmg`) ships from this version.

### Added

- Reproducible install: a fresh `git clone && pnpm install` runs without manual
  steps. `postinstall` downloads the Electron binary
  (`scripts/ensure-electron.mjs`), rebuilds `better-sqlite3` and `keytar` to
  Electron's ABI via `electron-rebuild`, then idempotently applies the
  electron-trpc patch (`scripts/apply-patches.mjs`). The patch wires superjson
  into electron-trpc's transformer; without it every tRPC call fails.
- macOS packaging via `pnpm package:mac` (`scripts/package-mac.mjs`): builds the
  app icon, compiles the napi addon for `aarch64-apple-darwin`, runs the app
  build, then `electron-builder --mac --arm64`. Output is
  `dist-installer/Omnidex-<version>-arm64.dmg` plus a matching `.zip`.
- Windows packaging via `pnpm package` (`scripts/package-win.mjs`): NSIS x64
  installer (`Omnidex-Setup-<version>.exe`). Must run on Windows; the script
  guards against non-`win32` platforms because the native modules cannot be
  cross-compiled.
- Real-asset test fixtures: `pnpm gen:test-library` generates an on-disk UE test
  library of real marketplace pack names; `pnpm smoke:scan <path>` runs the
  filesystem walker against a directory without Electron and prints detected
  folders.
- Vitest unit suite and a single Ubuntu CI job (`.github/workflows/ci.yml`)
  running `pnpm lint`, `pnpm check`, and `pnpm test:coverage` on push/PR to
  `master`. CI installs with `--ignore-scripts`; unit tests use Node's built-in
  `node:sqlite` instead of better-sqlite3. There is no build/package matrix in
  CI; installers are built locally.

### Changed

- Pinned toolchain: pnpm `11.1.3` (via `packageManager`) and Node 24
  (`.nvmrc`, `engines.node`). `pnpm-workspace.yaml` sets
  `strictDepBuilds: false` so a clean install prints the ignored-builds notice
  instead of failing.
- Pre-commit hook (Husky, `.husky/pre-commit`) runs
  `biome check --write --staged` and blocks the commit on any unfixable
  lint/format violation.

### Fixed

- Stopped shipping broken builds: builds now produce a working installer from a
  clean checkout.

### Known limitations

- Data operations run only from the CLI today; they are not wired into the
  running UI:
  - `pnpm refresh-scans` scans all active scan locations into the database.
  - `pnpm extract-thumbs` extracts missing thumbnails from `.uasset` files via
    the napi addon.
  - `pnpm enrich-orbital` matches assets against orbital-market.com and writes
    metadata.
  - `pnpm enrich-fab` pulls the user's FAB library (Epic OAuth) and enriches
    matches.
- The Settings "Scan now" button and the in-app scan/enrich controls are not
  connected to any action. The tRPC router exposes only `assets`,
  `scanLocations`, `collections`, `notes`, and `settings`; there is no
  `scanner` or `enrich` procedure. Adding a scan location does not trigger a
  scan of it.

## [2.0.0] - 2026-04-23

### Added

- FTS5 full-text search inside the local SQLite database
  (`20260423000000_add_fts5_search.up.sql`), backed by `fuse.js` for fuzzy
  matching and `fast-glob`/`fast-glob`-driven filesystem walking.
- Asset browsing UI: virtualized asset grid (`AssetGrid`), inspector panel with
  metadata, gallery, and shell actions (open file location / external URL).
- Filtering and sorting: source filters (all / favorites / fab / category /
  ecosystem), 14 sort options, debounced URL-bound text search, favorite toggle.
- Collections: create, delete, and add/remove assets via the `collections`
  tRPC router.
- Scan-location management: list, add (folder picker), pause/activate, and
  delete via the `scanLocations` tRPC router.
- Notes and settings persistence.

### Changed

- Migrated off the previous Tauri-era stack to Electron + React. The earlier
  Tauri/Rust-backend and Svelte/Vue frontends were removed along with their
  CI workflows and source directories. The only remaining Rust is the
  `@omnidex/uasset` napi addon under `native/uasset/`.
- Search moved into in-process SQLite FTS5; database access uses better-sqlite3
  with hand-written `.up.sql` migrations run by `electron/main/db/migrator.ts`.

### Removed

- Dead Tauri-era directories and the old platform build workflows.
